## 4. Defects found and corrected during this cycle

* **Run table status column (recorded in `results/sim02b2a/ERRATA.md`).** The `pfa_status` column of the run tables
  used a Wilson interval of the evaluation set only. That is the same defect class recorded for the SIM-02B.1
  self-check, repeated in a new column: it ignores threshold sampling error and flags 3 exceedances in 10,000 at Pfa
  1e-4 as liberal, which happens with probability 0.08 under correct calibration. No result value is affected; the
  run's self-check and the report use the exact predictive laws. Code after the run adds exact tails and an exact
  status column, with a test.
* **Self-check count and figure labels (ERRATA).** The method-agreement self-check counted identical NOMINAL rows
  twice (66 of 72; 33 of 36 distinct statistics); figure 6 lacked axis labels. Corrected in code after the run.
* **Caught by the claims checker before delivery.** The draft report said the not-estimated thresholds were all
  adaptive (108 of the 360 are ORACLE and NOMINAL rows for statistics other than the tonal maximum), quoted the
  coherence-mismatch maximum as 2.40 times target (it is 2.93), and miscounted the increment tests. All corrected.
* **SIM-02B.1 claims checker.** Its check of "214 tests at the packaging baseline" counted the tests of whatever
  tree it ran in, so it could pass only at that baseline; the SIM-02B.2-A package build caught this when it ran
  `make sim02b1-claims` from the new snapshot. It now checks the inventory recorded in the SIM-02B.1 package
  (committed as a test fixture) and requires every test in it to still exist. No SIM-02B.1 number changes.
* **Regression tool.** Its first version compared SIM-02B.1 union-bound rows as estimates and reported 21
  inconsistencies; bound rows are now tested one-sidedly (all 48 hold).
* **Before the run of record** (found in self-review and the smoke run, none in a delivered result): the
  contamination normalizer had no threshold (it now shares the threshold of the same estimator); a block
  approximation in the conditional Monte Carlo was replaced by every-bin estimation with common random numbers and
  its interval sign corrected; a reference-window axis error and two configuration-path errors were fixed; ADR-0020
  was corrected to name the implemented matrix-exponential method.

## 6. Principal findings

Stationary circular Gaussian noise; Wenz-type spectra with assumed parameters; assumed coherence and scenario
parameters (4 published records, 0 measured, 27 assumed). Operating point: 200 Hz to 2 kHz, 1 s windows, Pfa 1e-3
per window, Pd 0.5 (report Section 0).

1. False-alarm control with estimated backgrounds holds under the nominal design: 1,170 rows, 4.3 % of p-values
   below 0.05, none below 0.001.
2. Estimation costs tonal detection 2.10 dB on A0 and 2.51 to 2.63 dB with beam search, broadband 0.11 to 0.47 dB;
   the A0 loss matches the exact CFAR law within 0.13 dB.
3. The array advantage over A0 survives estimation: P8-C beam search keeps 2.83 to 3.05 dB of its 3.42 dB tonal gain.
   Below 200 Hz no compact candidate beats A0 (-0.26 to 0.72 dB).
4. Time references fail under a 1 dB level step (tonal false alarms 3.50 to 11.25 times target), under interference
   in the reference windows (4.52 to 5.42 dB extra loss) and against persistent targets (Pd never reaches 0.5);
   frequency references hold in all three but cannot serve broadband statistics.
5. No level estimator repairs a coherence mismatch: under flow-like coherence, 121 of 132 incoherent rows give no
   false alarm at Pfa 1e-2 and beam search runs up to 2.93 times target.
6. Pfa 1e-3 on 1 s windows is 3.6 false alerts per hour per detector.

Nothing here selects an architecture, estimates a detection range or sets a hardware requirement.

## 7. Decisions requested before SIM-02B.2-B

1. **Exit requirement.** Accept that SIM-02B.2-A meets its exit requirement within the stated model scope, and
   authorize SIM-02B.2-B.
2. **Robust multichannel covariance estimation (D01 gap).** Complete it as a SIM-02B.2-A supplement before
   SIM-02B.2-B (sample covariance with shrinkage and outlier-robust estimates, whitened and covariance-adaptive
   statistics, same scenarios and threshold methods), or fold it into SIM-02B.2-B.
3. **Normalizers for SIM-02B.2-B.** Carry frequency references for tonal, harmonic and chirp statistics and time
   references with the longer guard for broadband statistics, plus ORACLE as a bound and A0 with the same normalizer;
   or name a different set.
4. **Multichannel threshold law under coherence uncertainty** (finding 5): wait for D02 data, add a data-driven
   threshold calibration to SIM-02B.2-B, or both.
5. **Array thresholds at Pfa 1e-4.** Fund empirical calibration (at the n Pfa = 10 minimum, 2.5 to 3.0 core-hours per
   array in the 200 Hz to 2 kHz cell, from this run's timings; more for a 0.25 dB interval), or accept Pfa 1e-3 as the
   array reporting floor until a tail method covers those statistics.
6. **Target-aware reference censoring** (excluding windows that already hold a detection) as a SIM-02B.2-B item,
   given the contamination ceiling.
7. **D02:** approve the collection plan in principle and name candidate sites and host access.
8. **D05:** approve requesting loan and facility quotes for the bench evaluation outline.
